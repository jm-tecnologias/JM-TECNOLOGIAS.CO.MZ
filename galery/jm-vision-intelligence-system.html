Visão do produto

Análise de imagens com organização, contexto e evidência documental.

O JM Vision Intelligence System foi concebido para apoiar equipas que precisam transformar imagens dispersas em informação útil. A ferramenta centraliza a navegação, a leitura técnica, a localização geográfica e a geração de relatórios num fluxo único.

Organização local

Estrutura de pastas própria para importar, navegar e gerir imagens dentro do ambiente do utilizador.

Leitura técnica

Extração de metadados como fabricante, modelo, ISO, exposição, distância focal e datas da imagem.

Contexto geográfico

Identificação de coordenadas GPS e abertura da localização em mapa quando a imagem contém dados válidos.

Relatórios PDF

Geração de relatórios técnicos com dados da imagem e notas do utilizador para documentação formal.

Funcionalidades

Construído para o fluxo real de análise.

A aplicação combina interface desktop, processamento local de ficheiros, leitura de metadados e emissão de relatórios, mantendo o foco na produtividade de quem trabalha com imagens.

01

Selecionar pasta e carregar miniaturas

O utilizador navega pela árvore de diretórios e o sistema apresenta as imagens disponíveis para inspeção.

02

Visualizar imagem com zoom, pan e rotação

O preview central permite uma leitura visual mais confortável, incluindo aproximação, deslocamento e rotação.

03

Extrair EXIF e geolocalização

O sistema lê os metadados disponíveis e apresenta dados técnicos, datas, GPS e informação geográfica enriquecida.

04

Gerar relatório técnico

Com uma ou várias imagens selecionadas, o utilizador pode gerar documentos PDF para arquivo, partilha ou análise posterior.

Aplicação prática

Indicado para equipas que precisam analisar imagens com rigor.

O produto pode ser adaptado a diferentes contextos profissionais onde a imagem digital precisa de ser tratada como fonte de informação.

Análise e investigação

Consulta de dados técnicos, origem, datas e coordenadas para apoiar processos de verificação e documentação.

Operações com componente geográfica

Apoio a equipas que precisam relacionar imagens com localização, rotas, pontos de ocorrência ou áreas de trabalho.

Gestão documental

Organização de imagens e emissão de relatórios para anexar a processos internos, auditorias ou documentação técnica.

Base técnica

Software desktop com arquitetura modular.

O sistema foi desenvolvido com separação entre interface, controladores, serviços, modelo de dados e utilitários, permitindo evolução organizada e manutenção técnica mais segura.

JavaFX + FXML

Interface desktop construída com telas FXML, estilos CSS e componentes JavaFX.

Camada de serviços

Serviços dedicados para imagem, metadados, ficheiros, mapa, miniaturas e relatórios.

EXIF + JSON

Leitura de metadados com bibliotecas especializadas e enriquecimento de dados geográficos.

Empacotamento

Base preparada para distribuição Windows com runtime, app-image, instalador EXE ou MSI.
